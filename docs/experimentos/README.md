# Experimentos e historia de producto

Bitácora ligera de cambios impulsados por el uso real:
**observación → hipótesis → cambio → resultado**.

## Cómo se usa

1. Copia `PLANTILLA.md` a `AAAA-MM-DD-slug.md`.
2. Llena hasta "Métrica objetivo" **antes** de tocar el contenido.
3. Cierra el archivo cuando termine la ventana de seguimiento.

## Reglas

- **No se inventan datos.** Si no hubo medición, el resultado es "sin datos
  suficientes".
- **La revisión de contenido es obligatoria** en cualquier comparación
  antes/después: sin ella no se sabe si los intentos comparados corresponden a
  la misma versión del contenido (ver `docs/product-analytics.md` §7).
- **Los experimentos nulos también se documentan.** Saber qué no funcionó
  ahorra repetirlo.
- Un archivo por cambio. Si no cabe en una pantalla, sobra texto.
